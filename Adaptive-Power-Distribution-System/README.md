# Adaptive Power Distribution System

A 12 V DC power distribution system designed to provide regulated **5 V and 3.3 V outputs** for multiple loads, with input protection and individual output protection.

## Key Specifications

| Parameter | Specification |
|---|---|
| Input | 12 V DC |
| 5 V Output | 5 V / 1.5 A total |
| 3.3 V Output | 3.3 V / 0.3 A |
| Regulators | LM2596S-5 / LM2596S-3.3 |
| Input Protection | 3 A Fuse + Reverse Polarity Protection |
| Output Protection | Individual Polyfuses |
| Simulation | NI Multisim |
| PCB Design | KiCad |

## Highlights

- Dual regulated power rails: **5 V and 3.3 V**
- Reverse-polarity and overcurrent protection
- Individual protected output branches
- Custom schematic and PCB layout
- Simulation and waveform verification
- Engineering calculations and BOM included
